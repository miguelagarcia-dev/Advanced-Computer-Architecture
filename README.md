# Advanced-Computer-Architecture
ECE 451: Advanced Computer Architecture (Undergraduate)

## Project 1: CPU frequency vs. memory technology
A gem5 study of how CPU model, clock speed and DRAM type affect the runtime of a prime sieve: 30 simulation runs across 2 CPU models, 5 clock speeds and 3 memory types. Clock speed moved runtime by up to 1.84×, memory choice by up to 1.41×.

See [P1-gem5-cpu-vs-memory](P1-gem5-cpu-vs-memory/) for the setup, results and report.
